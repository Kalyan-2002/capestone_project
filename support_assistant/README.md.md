# Zepto Support Assistant — Module 3

## Overview

This project implements a small GenAI support assistant for Zepto.

The system uses:

- Sentence Transformers
- all-MiniLM-L6-v2
- ChromaDB
- LangGraph
- TypedDict
- FastAPI
- Pydantic
- Deterministic MOCK_LLM baseline

The default configuration is:

```text
MOCK_LLM=1
